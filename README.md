# Customer Shopping Behavior Analysis

This project analyzes **3,900 customer purchase transactions** to identify shopping patterns, customer segments, revenue trends, and factors influencing purchasing behavior. The analysis uses **Python (Pandas)** for data preparation and exploration, with **PostgreSQL** for database integration.

Key areas include customer segmentation, gender-based revenue analysis, discount usage, shipping preferences, subscription impact, and top-rated products. The project provides actionable business recommendations focused on **customer retention, loyalty programs, subscriptions, targeted marketing, and product positioning**.
